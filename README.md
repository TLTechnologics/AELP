# AELP (Adaptive English Learning Platform)

A next-generation, AI-powered Adaptive English Learning Platform.

## 🚀 Features
- **Student UI/UX:** A stunning, mobile-responsive, minimalist interface inspired by Apple Education, Linear, and Duolingo.
- **Diagnostic Assessment:** Dynamic entry test to place students correctly.
- **Learning Path:** A gamified, interactive roadmap of lessons.
- **Skill Dashboards:** Dedicated dashboards for Listening, Reading, Writing, and Speaking.
- **Leaderboards & Progress:** Deep analytics, XP tracking, and league systems.
- **Built with:** Next.js, React, Tailwind CSS, shadcn/ui, Framer Motion, Lucide Icons.

## 💻 Getting Started

First, run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the platform.
