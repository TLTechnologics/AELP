SECTION 1 - GLOBAL / DESIGN SYSTEM
============================================================================================

[BUG-001] globals.css | DARK MODE FORCED OFF
  ThemeProvider has forcedTheme="light" in layout.tsx, so the entire dark-mode color palette
  is dead code. Remove forcedTheme or build a proper theme toggle.

[BUG-002] globals.css | HOVER BOX-SHADOW TOO WEAK
  .hover-card-up:hover uses near-zero opacity shadows (0.05, 0.01). The lift effect is
  invisible. Should be at least rgba(15,23,42,0.12) to read as a real elevation change.

[BUG-003] globals.css | GRID PATTERN INVISIBLE
  .bg-grid-pattern uses 0.02 opacity lines - imperceptible on any monitor.
  Raise to 0.05-0.08 or use a dot-grid approach with better contrast.

[BUG-004] globals.css | NO @keyframes FOR SPIN-SLOW
  profile/page.tsx references animate-spin-slow on the decorative dashed ring, but no
  @keyframes for spin-slow is defined anywhere. The ring will NOT animate.

[BUG-005] globals.css | FONT LOADING RACE CONDITION
  Satoshi is loaded via fontshare CDN <link> while Anton is via next/font. This split
  causes FOIT (flash of invisible text). Move Satoshi to next/font or self-host it.

[IMPROVE-001] globals.css | ADD TRANSITION TO body
  No transition for color/background. If dark mode is re-enabled, colors will flash.
  Add: transition: background-color 0.25s ease, color 0.25s ease.

[IMPROVE-002] globals.css | NO GLOBAL FOCUS-VISIBLE RING
  Add: :focus-visible { outline: 2px solid var(--color-brand-yellow); outline-offset: 3px; }
  to ensure keyboard navigation is always visible across every element.

[IMPROVE-003] globals.css | CUSTOM SCROLLBAR NOT STYLED
  Several panels use overflow-y-auto but no ::-webkit-scrollbar styles exist.
  Add thin scrollbar with brand-yellow thumb for a polished look.

[IMPROVE-004] DESIGN SYSTEM | NO PAGE TRANSITION ANIMATION
  Pages hard-cut on navigation. Add AnimatePresence page wrapper at layout level.

[IMPROVE-005] DESIGN SYSTEM | INCONSISTENT SHADOW TOKENS
  Cards use shadow-sm, shadow-md, shadow-xs, shadow-xl ad-hoc. Define a consistent
  shadow scale as CSS variables.

  Currently the loader shows an abstract "A" with no branding context.

  and the onboarding screen is the entry point for every new user.
